SIMULADOR ATM - NETBEANS
========================

***********************************
El desarrollo del Simulador de ATM se realizó inicialmente de manera local y fuera de este repositorio de GitHub. Durante las primeras etapas del proyecto, el código fue creado, probado y modificado antes de ser incorporado al repositorio.

Por esta razón, el historial de GitHub no refleja todos los cambios, avances y etapas de desarrollo realizados durante el proyecto, y puede observarse una cantidad reducida de commits. Posteriormente, el código desarrollado fue integrado y actualizado en este repositorio para mantener la versión final del proyecto y facilitar su documentación y entrega.

***********************************

Cómo abrirlo:
2. Abrir NetBeans.
3. File > Open Project.
4. Seleccionar la carpeta Proyecto_SimuladorATM.
5. Ejecutar ATMApp.java con Run File.
