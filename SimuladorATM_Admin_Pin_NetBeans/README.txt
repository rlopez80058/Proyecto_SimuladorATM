SIMULADOR ATM - NETBEANS
========================

Proyecto Java listo para abrir en NetBeans.

Cómo abrirlo:
1. Descomprimir el archivo ZIP.
2. Abrir NetBeans.
3. File > Open Project.
4. Seleccionar la carpeta SimuladorATM_Admin_NetBeans.
5. Ejecutar ATMApp.java con Run File.

Datos de prueba:
Tarjeta: 1111222233334444 | PIN: 1234
Tarjeta: 5555666677778888 | PIN: 4321

Módulo administrador:
En la pantalla principal del cajero, usar el botón ADMIN USUARIOS.
Permite crear, editar, eliminar usuarios y desbloquear tarjetas.

Ejemplo de usuario nuevo:
Identificación: 3-3333-3333
Nombre: Ignacio Cascante
Tarjeta: 9999888877776666
PIN: 2026
Cuenta: 3001
Tipo: Ahorros
Saldo inicial: 100000

Luego se puede iniciar sesión con:
Tarjeta: 9999888877776666
PIN: 2026

Nota:
Los datos se manejan en memoria durante la ejecución. Al cerrar el programa, se vuelve a cargar la información de prueba.
